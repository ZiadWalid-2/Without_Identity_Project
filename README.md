# Without_Identity
## Motion Graphics Graduation Project — DEPI
## Project Overview

**Without Identity** A motion graphics project that explores a common social issue people experience in their everyday lives. It sheds light on the hidden struggles individuals face while navigating social expectations, relationships, and the pressure to fit in. Through a relatable narrative and meaningful visual storytelling, the project aims to encourage self-reflection and raise awareness of an issue that many people experience but rarely talk about.

## Project Objectives

* Raise awareness about an important social issue.
* Communicate a meaningful message through visual storytelling.
* Use Motion Graphics to express emotions and ideas.
* Develop animation, typography, and sound design skills.
* Deliver a polished and engaging final video.

## Project Scope

The project will include research, concept development, scriptwriting, storyboarding, visual design, animation, sound design, editing, and final rendering.

## Project Plan — 5 Weeks

### Week 1: Research and Concept

* Research the selected social issue.
* Define the target audience and main message.
* Develop the concept and initial storyboard.

### Week 2: Visual Development

* Define the visual style and color palette.
* Create visual assets and style frames.
* Finalize the storyboard.

### Week 3: Animation

* Animate the main scenes and visual elements.
* Create transitions and refine timing.

### Week 4: Sound and Refinement

* Add music and sound effects.
* Improve animation and visual consistency.
* Review feedback and make revisions.

### Week 5: Final Delivery

* Complete final revisions.
* Render and review the final video.
* Organize project files and prepare the final presentation.

## Deliverables

* Final Motion Graphics video.
* Storyboard and visual development materials.
* Project documentation.
* Source project files, where applicable.
